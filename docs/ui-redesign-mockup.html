开水卡（缺渴）

状态怎么进入状态区显示按钮行
空闲默认 / 完成 / 关闭后使用积分抵扣 + 开关【开水】

开阀中点【开始洗澡】当前步骤（转圈）【开启中…】禁用
洗澡中开阀成功自动计时 + 预扣 + 闲置关停倒计时【结束使用】（红描边）
结算点【结束使用】本次消费金额 + 用时【完成】
失败开阀 / 关阀出错红字原因 + 详情›（关阀失败会强调重试）【重试关阀】【关闭】

相比现状改了什么

  1. 首页三个平权功能区：开水 / 洗澡 / 快捷方式；开水卡与洗澡卡骨架、交互完全统一。
  2. 「积分余额」大卡与「每日签到」卡取消：积分缩成顶栏数字，小票 + 签到按钮压缩成一条状态行。
  3. 进行中 / 结算 / 报错不再弹窗、不再插入新卡片，全部在原卡状态区原地切换，高度变化约一行以内，带 200ms 动画（实现用 Compose 的 AnimatedContent + animateContentSize）。
  4. 换设备交互统一：两张卡都是点设备名弹出选择（开水 = 设备列表；洗澡 = 扫描 / 手输 MAC 列表）。
  5. 淋浴卡五种状态紧凑化；设置页按平台分组并统一视觉。
  6. 状态机与数据层不动，只改界面（SimpleScreen / QzxySection / SettingsScreen）。
