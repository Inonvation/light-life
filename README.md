# LightLife

LightLife 是集成了胖乖生活开水和趣智校园开热水功能的校园生活助手。基于 [wzs0512/qiekj-android](https://github.com/wzs0512/qiekj-android) 重构，Jetpack Compose + Material3，安装包约 2MB。

> **⚠️ 重要说明**
>
> 经多账号多设备排查，除签到外的原脚本接口疑似已被官方更改，目前所有旧版本及其他项目的积分脚本均已失效，刷积分功能随之废弃，自本版本起移除。
>
> 本版本删除了刷分、备份、日志、喝水提醒等废弃模块，保留开水、签到、余额查询、数据统计与快捷方式，并新增趣智校园（淋浴热水器控制）。不排除以上接口未来再次变更的可能。
>
> **本项目已停止维护**，不再有新功能与问题修复，全部后续开发已转入新项目 [JUWP Schedule（水贝贝）](https://github.com/Inonvation/JUWP-Schedule)——功能更完整、仍在持续维护，建议改用（见下节）。
>
> 如需继续使用刷分功能，可保留 v3.0.0 之前的版本；升级到 v3.0.0 前请先进行数据备份。
>
> 感谢使用。

## 后继项目：JUWP Schedule（水贝贝）

[JUWP Schedule](https://github.com/Inonvation/JUWP-Schedule) 是同一作者开发、同样面向江西水利电力大学学生的 Android App，以课表为主线，本项目原有的胖乖生活（开水）与更完整的趣智校园（含蓝牙款开热水直控）均已整合其中，且持续维护。

**主要功能**：课表导入与调课检测、成绩 / 考试 / 学业、选课（beta）、校园一卡通付款码、寝室电费、胖乖生活、趣智校园开热水、快趣出行、U净洗衣房、校历、学工表单、桌面小组件等。

**实现**：Kotlin + Jetpack Compose，与本项目同一技术路线；教务、胖乖、趣智（含蓝牙直控的签名与帧协议）等各家平台的逆向实现有完整文档，见其仓库 [DEVELOPER.md](https://github.com/Inonvation/JUWP-Schedule/blob/main/DEVELOPER.md)。更详细的实现请参考该项目。

## 功能

- **登录**：手机验证码登录、Token 登录
- **开水**：历史设备一键开水，支持积分抵扣，订单详情自动保存
- **每日签到**：打开 App 自动签到（可在设置中关闭），也可手动签到
- **余额查询**：实时查询积分余额、可抵扣金额、剩余小票
- **洗澡 · 趣智校园**：登录、绑定淋浴热水器、开阀 / 停阀 / 结算；蓝牙款设备由手机蓝牙直控（本校宿舍即为蓝牙款）
- **数据统计**：累计开水次数、订单记录
- **快捷方式**：自定义快捷链接、添加到桌面、设备快捷方式
- **主题与触感**：深色模式、主题配色、触感反馈

## 使用

1. 打开 App，手机号验证码登录，或粘贴 Token 登录
2. 首页选择饮水机设备，点击「开水」；淋浴热水器在「洗澡」卡片里绑定后使用
3. 每日签到在打开 App 时自动执行（可在设置中关闭），也可手动点击签到
