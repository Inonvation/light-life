# LightLife

LightLife 是集成了胖乖生活开水和刷积分脚本等功能的软件。基于 [wzs0512/qiekj-android](https://github.com/wzs0512/qiekj-android) 重构，Jetpack Compose + Material3，安装包约 2MB。

> **⚠️ 重要说明**
>
> 经多账号多设备排查，除签到外的原脚本接口疑似已被官方更改，目前所有旧版本及其他项目的积分脚本均已失效，刷积分功能随之废弃，自本版本起移除。
>
> 本版本仅保留开水、签到、余额查询、数据统计与快捷方式等基础功能，并已删除大量废弃代码。不排除以上接口未来再次变更的可能，但当前仍可替代官方部分功能，如一键开水。
>
> 本项目已停止维护。如需继续使用刷分功能，可保留 v3.0.0 之前的版本；升级到 v3.0.0 前请先进行数据备份。
>
> 若有大佬更新了脚本，欢迎提交 issue 或 fork 本项目继续开发。
>
> 感谢使用。

## 功能

- **登录**：手机验证码登录、Token 登录
- **开水**：历史设备一键开水，支持积分抵扣，订单详情自动保存
- **每日签到**：打开 App 自动签到（可在设置中关闭），也可手动签到
- **余额查询**：实时查询积分余额、可抵扣金额、剩余小票
- **数据统计**：累计开水次数、订单记录
- **快捷方式**：自定义快捷链接、添加到桌面、设备快捷方式
- **主题与触感**：深色模式、主题配色、触感反馈

## 使用

1. 打开 App，手机号验证码登录，或粘贴 Token 登录
2. 首页选择饮水机设备，点击「开水」
3. 每日签到在打开 App 时自动执行（可在设置中关闭），也可手动点击签到
