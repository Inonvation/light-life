# LightLife

胖乖生活饮水机积分助手最终版。基于 [wzs0512/qiekj-android](https://github.com/wzs0512/qiekj-android) 重构，Jetpack Compose + Material3，安装包约 2MB。

> [!IMPORTANT]
> 胖乖生活官方已下线刷视频等积分活动，相关接口随之变更。自 **v3.0.0** 起，本 App 移除刷分功能，仅保留登录、开水、每日签到、数据统计与快捷方式。此版本为项目最终版，停止功能开发。

## 下载

前往 [Releases](https://github.com/Inonvation/light-life/releases) 下载最新 APK。

## 功能

- **登录**：手机验证码登录、Token 登录
- **开水**：选择历史设备一键开水，支持积分抵扣，订单详情自动保存
- **每日签到**：打开 App 时自动签到（可在设置中关闭），也可手动点击签到
- **数据统计**：积分余额、可抵扣金额、剩余小票、累计开水次数、订单记录
- **快捷方式**：自定义快捷链接、添加到桌面、设备快捷方式
- 主题与深色模式、触感反馈

## 使用

1. 打开 App，手机号验证码登录，或粘贴 Token 登录
2. 首页选择饮水机设备，点击「开水」
3. 每日签到自动执行，打开 App 即可；今日状态显示在签到卡片
